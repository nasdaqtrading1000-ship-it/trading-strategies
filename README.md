# Code Markets

Aplicacion web para consultar y gestionar servicios de Code Markets.

## Contenido privado

Este repositorio no incluye:

- Estrategias ni reglas de trading privadas.
- Credenciales, claves API, tokens o contrasenas.
- Bases de datos, historicos, operaciones o configuraciones locales.
- Datos personales de usuarios.

La configuracion sensible se proporciona exclusivamente mediante variables de entorno y almacenamiento local seguro.

## Aviso

El contenido es informativo. El trading implica riesgo y no garantiza resultados.
